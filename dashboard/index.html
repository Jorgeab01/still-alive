What is this page?

I run a home server on a laptop from 2008. Old hardware fails in ways new hardware doesn't: it overheats more, it has no battery backup, and if it goes down while I'm away, I have no way of knowing unless I check manually.

This page shows whether it's actually alive right now, plus how it's been doing over the last 30 days and the last 24 hours.
